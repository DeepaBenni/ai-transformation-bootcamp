Hardware token codes that are consistently rejected while the token still displays a code indicate clock drift between the token and the server. Resynchronise the token by submitting two consecutive codes in the admin console. Tokens more than five minutes out of drift cannot be resynchronised and must be replaced. Software tokens on a phone drift only if the device clock is set manually; ensure automatic time is enabled. Repeated resynchronisation requests for the same token within a month indicate a failing device and it should be swapped rather than resynchronised again.
