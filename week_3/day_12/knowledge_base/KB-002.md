---
id: KB-002
title: "Outlook prompts repeatedly for a password"
type: article
status: current
last_reviewed: 2026-08-20
---

Repeated credential prompts in Outlook are usually caused by a stale cached credential in Windows Credential Manager rather than an expired password. Clear all entries beginning with MicrosoftOffice16 and restart Outlook. If prompts continue, confirm the mailbox has not been migrated to a different Exchange region; a mid-migration mailbox will prompt indefinitely. Modern Authentication must be enabled on the tenant. This issue does not affect Outlook Web Access, so a working OWA session is a reliable signal that the account itself is healthy and the fault is local to the desktop client.
