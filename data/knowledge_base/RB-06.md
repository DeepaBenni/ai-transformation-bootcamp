note: "Predates the OneDrive rollout. Step 3 is the single most common cause of user data loss."
---

Step 1: Establish the exact filename and the last known good date from the user. Step 2: Check the Previous Versions tab on the file share before opening a backup request, as most restores can be self-served. Step 3: For a OneDrive file, delete the local sync folder and allow the client to download a fresh copy from the server, which is the fastest route to a clean restore. Step 4: For file-share content, raise a restore request with the Backup team quoting the share path and the target date. Step 5: Restores older than ninety days require Information Security approval. Step 6: Confirm with the user that the restored file opens before closing the ticket.
