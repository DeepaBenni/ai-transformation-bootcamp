---
id: KB-004
title: "Shared drive mapping disappears after reboot"
type: article
status: current
last_reviewed: 2026-08-20
---

Mapped network drives that vanish on restart are almost always caused by the drive being mapped in the user session rather than through Group Policy Preferences. Confirm the mapping appears in gpresult output. If it does not, the user has mapped it manually and it should be migrated to the correct GPO. A second cause is fast startup on Windows 11, which restores a session before the network stack is ready; disabling fast startup resolves this. Do not use persistent net use commands as a workaround - they mask the underlying policy gap and break when the user changes department.
