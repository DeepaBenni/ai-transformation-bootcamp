If the Microsoft Authenticator push does not arrive, first confirm the user's device has data connectivity and that battery optimisation is not suspending the app. Android devices place Authenticator in a restricted state after long idle periods. Have the user open the app manually, which forces a poll. If the push still fails, fall back to the six-digit code, which works entirely offline and does not depend on push delivery. Hardware tokens were withdrawn from the estate in 2025 and are no longer supported; a hardware token must never be resynchronised, it must be collected and replaced with the Authenticator app. Persistent failures across multiple users indicate a tenant-level notification issue and should be escalated to Identity Services rather than handled per-user.
