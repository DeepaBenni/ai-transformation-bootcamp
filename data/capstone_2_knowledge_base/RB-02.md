title: "Runbook: Onboarding a new starter"
type: runbook
status: current
last_reviewed: 2026-08-20
---

Step 1: Confirm the HR record is complete, with start date and cost centre populated. Step 2: Verify the account was created by the nightly feed; if not, raise a manual creation request with hiring-manager approval. Step 3: Assign the licence bundle matching the job family. Step 4: Add the user to the department security groups from the role template - never copy another user's group membership, as this propagates access errors. Step 5: Enrol the device and confirm the disk encryption key escrowed successfully. Step 6: Book the user onto the security induction. Step 7: Confirm first-day login with the user before closing the ticket.
