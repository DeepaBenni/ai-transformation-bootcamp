---
id: KB-022
title: "Slow file access over the WAN at branch sites"
type: article
status: current
last_reviewed: 2026-08-20
---

Branch users opening large files from head-office shares experience latency proportional to file size because the protocol is chatty over high-latency links. This is expected and is not a bandwidth fault; adding bandwidth will not materially improve it. The correct remedy is to move the working set to the branch cache or migrate the content to SharePoint, which is optimised for this access pattern. Confirm the round-trip time to head office; above 60ms the effect becomes clearly noticeable to users on files larger than 20MB.
