---
id: KB-019
title: "Excel file locked for editing by another user"
type: article
status: current
last_reviewed: 2026-08-20
---

A file reported as locked when nobody has it open is usually holding a stale lock left by a client that crashed or lost network connectivity. The lock clears automatically after ten minutes of inactivity. If it does not, the file's owner shown in the message is the account that holds the lock, and the session can be closed from the file server's open-files console. For files in SharePoint or OneDrive, co-authoring should be used instead; a persistent lock there indicates the file is open in the desktop client with an unsaved change.
